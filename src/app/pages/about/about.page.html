L’application

DevFestCamer

DevFestCamer est une application compagnon pour les DevFest du Cameroun, pensée pour être légère, installable et utilisable hors-ligne. Chaque édition possède ses propres données : l’application ne dépend pas d’une API distante pour afficher le programme ou le plan.

Comment mettre à jour une édition

Tout le contenu vit dans des fichiers JSON versionnés avec le code. Pour corriger un texte ou ajouter une session, modifiez le fichier de l’année puis reconstruisez l’application. 

src/assets/data/
        ├── editions.json   # index des années
        ├── {{ c.year }}.json       # contenu complet de l’édition
      └── ...

Une nouvelle année = un nouveau fichier {{ c.year + 1 }}.json et une entrée dans editions.json qui n’est plus planned. Les routes acceptent déjà n’importe quelle année : /{{ c.year + 1 }}/agenda fonctionnera dès que ces deux conditions sont remplies.

Les participant·es et certains témoignages de cette édition sont des exemples marqués demo. Remplacez les URL example.com par les vrais liens avant la mise en ligne.
