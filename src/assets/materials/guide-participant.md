# Guide du participant — DevFest Douala 2026

## Avant d'arriver

- Inscrivez-vous via la page GDG Community et gardez le QR code de confirmation accessible (email ou capture d'écran).
- Prévoyez une pièce d'identité et, si possible, une batterie externe.
- L'app companion fonctionne hors-ligne : ouvrez-la une première fois avant de partir.

## Accès

**JFN Hightech University Institute**
Campus Universitaire Santa Barbara, Bonamoussadi (Douala 5e).
Repère : Carrefour Santa Barbara.

- **Taxi / moto** : demandez « JFN University Institute » ou « Carrefour Santa Barbara ».
- **Stationnement** : places disponibles à proximité du campus.
- **Accueil** : l'entrée principale ouvre à 07:00.

## Sur place

1. Retrait du badge à l'accueil (scan du QR code).
2. Le programme est affiché dans l'app et sur les écrans du campus.
3. Les salles sont indiquées sur le plan du lieu dans l'app.
4. Le wifi est communiqué à l'accueil ; les sessions ne dépendent pas d'une connexion.

## Bonnes pratiques

- Respectez le code de conduite.
- Posez vos questions après les talks ou sur les stands.
- Les photos officielles seront partagées après l'événement ; demandez toujours l'accord avant de photographier quelqu'un.
